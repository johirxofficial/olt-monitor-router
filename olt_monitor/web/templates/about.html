A self-hosted network monitor for EPON / GPON OLTs and MikroTik RouterOS routers. It polls every device over SNMP or the RouterOS API, stores the current state and history in MySQL, correlates PPPoE subscribers with the ONU they are connected to, and shows everything in a single web dashboard with role-based access.

What it does
  • OLT inventory: ports, PON ports, ONUs, VLANs, uplinks
  • Per-ONU optical power (Rx / Tx / OLT Rx), temperature, distance
  • ONU state changes and offline detection
  • PoE / PPPoE user list per router with live traffic counters
  • Automatic PPPoE user ↔ ONU correlation (FDB, MAC, ARP, templates)
  • Alert engine: weak optics, dead PONs, CPU / RAM / temperature
  • History graphs, SQL backup / restore from the browser
  • Multi-vendor: VSOL, BDCOM, C-Data, Huawei / ZTE-style profiles
Built with

Python 3.10+ · FastAPI · Jinja2 · MySQL 8 · PyMySQL · Bootstrap 5 · Chart.js · a small stdlib SNMP client and a native RouterOS API client · systemd
