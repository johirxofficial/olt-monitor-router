A self-hosted network monitor for EPON and GPON OLTs and MikroTik RouterOS routers. It polls every device over SNMP or the RouterOS API, stores current state and history in MySQL, links PPPoE subscribers to the ONU they sit behind, and shows it all in one dashboard with role-based access.

What it does

  • OLT inventory: ports, PON ports, ONUs, VLANs, uplinks
  • Per-ONU optical power (Rx, Tx, OLT Rx), temperature, distance
  • ONU state changes and offline detection
  • PPPoE user list per router with live traffic counters
  • Automatic PPPoE to ONU correlation (FDB, MAC, ARP, templates)
  • Alerts for weak optics, dead PONs, CPU, RAM and temperature
  • History graphs, plus config-only site backup in the browser
  • Multi-vendor: VSOL, BDCOM, C-Data, Huawei, ZTE-style, Photon

Built with

Python 3.10+ · FastAPI · Jinja2 · MySQL 8 · PyMySQL · Bootstrap 5 · Chart.js · a small stdlib SNMP client and a native RouterOS API client · systemd
